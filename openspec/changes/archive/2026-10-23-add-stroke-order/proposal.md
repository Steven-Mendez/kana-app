## Why

The Syllabary shows each kana's reading but not how to write it. Stroke order is the most useful thing a learner can get from a reference screen, and the QuickKana prototype already proved a suitable open dataset.

## What Changes

- Tapping a kana in the Syllabary shows an animated stroke-order diagram instead of the static glyph: strokes appear one at a time with the current stroke highlighted and a number at each stroke's start, followed by a Replay strokes action.
- Yōon show both glyphs side by side with numbering that continues across them.
- Reduced motion shows the finished, numbered diagram without animation.
- Stroke data for every catalogue glyph (148, including small kana) is bundled offline as JSON generated by `scripts/generate-kana-strokes.mjs` from ailectra/kana-json v0.0.1 (derived from AnimCJK, LGPL-3.0-or-later, redistributed unmodified with attribution in `src/data/kana-strokes.md`).
- Rendering uses `react-native-svg`, so it works on iOS, Android and web.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `study-overview`: Syllabary stroke-order diagram.

## Impact

New `react-native-svg` dependency (new native build), ~171 KB of JSON (57 KB gzipped) in the bundle, a generation script, a `KanaStrokes` component, the Syllabary panel, localized copy and tests.
