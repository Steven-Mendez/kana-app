# Kana stroke data

`kana-strokes.json` maps every catalogue glyph (including the small kana used by
yōon) to Hanzi Writer's `{ strokes, medians }` format. It is generated by
`scripts/generate-kana-strokes.mjs`; do not edit it by hand.

Source: https://github.com/ailectra/kana-json (v0.0.1), derived from AnimCJK
(https://github.com/parsimonhi/animCJK). AnimCJK's kana data is licensed under
